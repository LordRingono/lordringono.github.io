Relecture indépendante des pages sources et des passages de cours cités ci-dessous. Aucun fichier de données ni lot déjà livré n’a été modifié.

## Conclusion

Les deux ajouts épithéliaux correspondent aux clés **ABE** et **AB**, sans réserve concrète justifiant une nouvelle annotation scientifique. La séparation de C et D dans **histo.ann.tc8** est une réparation d’import étayée. **C vrai et D faux sont tous deux conformes à la ronéo TC3 fournie.** La clé ABCE peut rester inchangée.

## Histo annales TE — nouvel ID28, QRM9 de juin 2024 session 2

Sujet : *Annales Tissu épithélial NON corrigé 2020 2026.pdf*, p5. Correction : *Annales Tissu Epithélial 2020 2026 CORRECTION.pdf*, A/B p5 puis C/D/E p6.

| Item | Verdict explicite | Contrelecture |
|---|---|---|
| A — cellules jointives, étroitement juxtaposées | Vrai | Repris dans TE1 actualisé p2 |
| B — solidarisation par des jonctions | Vrai | Repris dans TE1 actualisé p2 |
| C — filaments intermédiaires constitués de vimentine | Faux | Le cours définit les FI épithéliaux par les cytokératines, TE1 p2 ; le corrigé précise les épithéliums apparentés dans son commentaire |

Cette précision ne justifie pas, à elle seule, un signalement d’erreur du verdict donné.

## Histo annales TC8 — QRM29, items C et D

Sujet : *annales TISSU CONJONCTIF 2020 2025.pdf*, p2. Correction : *annales TISSU CONJONCTIF 2020 2025 CORRECTION-2.pdf*, p2.

- **C** s’arrête après « les ostéoblastes périphériques forment le périoste ». Il est explicitement vrai dans le corrigé. **TC3 2026.pdf p16** reprend la même formulation dans l’étape 3 de l’ossification de membrane : les ostéoblastes situés au milieu forment de nouveaux clusters, ceux en périphérie forment le périoste. Une annotation qui présenterait C comme étant en contradiction avec cette ronéo serait donc incorrecte. Le haut de la même page décrit les couches conjonctive et progénitrice du périoste ; une discussion plus fine de l’histogenèse exigerait une autre référence et doit rester une réserve, pas une erreur certaine.
- **D** est bien une proposition indépendante : « l’ossification endochondrale est un processus moins long que l’ossification de membrane ». Le corrigé la déclare fausse. **TC3 2026.pdf p17** indique expressément que le processus endochondral est plus long. Aucune nouvelle réserve scientifique n’est nécessaire.

Les passages de cours consultés sont *Tissu épithélial 1 - CG ACTUALISE.pdf* pp2–3,6–7,9,14 ; *Tissu épithélial 2 - CG - ACTUALISE.pdf* p2 ; *TC3 2026.pdf* pp16–17. Les numéros de page sont ceux du PDF, sauf précision contraire.
