44. Soit le composé F qui réagit dans un 1ere étape avec NaOH, suivie d’une réaction avec CH3Br :
A. F est un alcool secondaire.
B. La 1ere étape conduit à un alcoolate.
C. Après la deuxième étape, on obtient 2 éthers isomères de configuration.
D. La réaction avec CH3Br est une réaction d’addition nucléophile.
E. La réaction CH3Br est une SN1.
DETAIL ORIGINAL
AB
A. VRAI : le groupement hydroxyle est porté par un carbone secondaire (qui est lié à deux autres
carbones).
B. VRAI : la réaction ci-dessus est une formation d’éthers par réaction Williamson. La première
étape est par conséquent la formation d’alcoolate.
C. FAUX : F étant un alcool secondaire, la réaction se fait selon le mécanisme SN2 (inversion de
Walden). On observe donc une seule configuration possible sur les éthers obtenus.
D. FAUX.
E. FAUX : SN2
DETAIL SITE (si différent)
NOTES
Le détail C invoque une inversion de Walden parce que F est un alcool secondaire. Dans la synthèse de Williamson dessinée, l’alcoolate attaque le carbone du bromométhane CH₃Br : la substitution SN2 ne se fait pas sur le carbone portant initialement OH dans F. Celui-ci porte deux groupes benzyle identiques. Le verdict faux est conservé, mais l’explication stéréochimique doit être précisée. La clé officielle est conservée ; vérifier ce point dans la ronéo et, si nécessaire, le faire préciser par l’enseignant.

A. Si on augmente la température, la réaction est déplacée dans le sens direct
B. Si on ajoute du 𝐷(𝑠), la réaction est déplacée dans le sens indirect
C. Si on ajoute du 𝐶(𝑙), la réaction est déplacée dans le sens indirect
D. Si on augmente la pression, la réaction est déplacée dans le sens direct
E. La réaction dans le sens indirect est exothermique
DETAIL ORIGINAL
CD
A. FAUX : si on augmente la température, on va aller dans le sens endothermique or ∆𝐻𝑟< 0
→ réaction exothermique donc on va aller dans le sens indirect.
B. FAUX : l’ajout d’un solide n’a aucun effet sur le déplacement de la réaction.
C. VRAI : on va dans le sens de la diminution de ce produit donc dans le sens indirect
D. VRAI : on a une enceint indilatable donc les lois de pression s’appliquent : on va aller dans
le sens de la diminution du nombre de moles de gaz donc dans le sens direct (car 3 moles
de gaz du côté des réactifs contre 0 mole de gaz du côté des produits)
E. FAUX : la réaction dans le sens direct est exothermique
DETAIL SITE (si différent)
NOTES
Le corrigé suppose qu’ajouter l’espèce notée (l) déplace nécessairement l’équilibre. Cette conclusion dépend de son statut : l’activité d’un liquide pur formant une phase distincte reste approximativement égale à 1 ; en ajouter ne déplace alors pas l’équilibre tant que la phase subsiste. La ronéo introduit le quotient réactionnel et les activités, mais ne résout pas cette ambiguïté de phase ; faire confirmer l’hypothèse du QCM dans le cours d’équilibres hétérogènes.
