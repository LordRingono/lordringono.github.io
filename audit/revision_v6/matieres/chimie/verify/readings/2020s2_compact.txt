===== 2020s2 atomistique Q27 ID1 CLE BDE =====
SUJET ORIGINAL
p338
Concernant l’atome 34Se :
Aide aux calculs :
0,35×2 = 0,7 ; 0,35×3 = 1,05 ; 0,35×4 = 1,4 ; 0,35×5 = 1,75 ; 0,35×6 = 2,1 ; 0,35×7 = 2,45 ;                    0,35×8 =
2,8 ; 0,85×2 = 1,7 ; 0,85×3 = 2,55 ; 0,85×4 = 3,4 ; 0,85×5 = 4,25 ; 0,85×6 = 5,1 ;                 0,85×7 = 5,95 ; 0,85×8
= 6,8
A. Il possède 16 électrons de valence
B. Il possède 28 électrons de cœur
C. L’ion Se2+ présente une configuration de gaz rare
D. Sa charge nucléaire effective, pour un électron 3p, est égale à 22,75
E. Dans la classification périodique, il est situé dans la même colonne que 8O
DETAIL ORIGINAL
BDE
A. FAUX : 34 Se : 1s2 2s2 2p6 3s2 3p6 4s2 3d10 4p4 ; atome du bloc p donc pour déterminer le nombre
d’électrons de valences on prend les ns + np de la dernière couche. Sois 2 + 4 = 6 électrons de valences
B. VRAI : Les électrons de cœurs étant tous les électrons qui ne sont pas de valences on a :       34 – 6 = 28
C. FAUX : Un gaz rare a une configuration s2 p6 ; l’ion Se2+ est l’atome de Se à qui on a arraché 2 électrons
; ça configuration étant 4s2 4p4 à l’état normal, si on lui arrache 2 électrons ça configuration sera 4s2
4p2
D. VRAI : On étudie un électron sur la couche 3p donc on prend en compte les électrons présents sur la
couche 1s, 2s 2p et 3s 3p en oubliant pas les coefficients d’écrantage ; au final on a : 2 électrons sur la
couche 1s, 8 électrons sur la couche 2s 2p et 7 électrons sur la couche 3s 3p car l’électrons que l’on
étudie ne s’écrante pas lui-même ; 34 - 2*1 + 8*0,85 + 7*0,35 = 34 - 2 + 6,8 + 2,45 = 34 - 11,15 = 22,75
E. VRAI : 8O : 1s2 2s2 2p4 ; 34 Se : 1s2 2s2 2p6 3s2 3p6 4s2 3d10 4p4 ; Ils possèdent le même nombre d’électrons
sur leur dernière couche p, ils sont donc sur la même colonne.
DETAIL SITE (si différent)
NOTES
Le détail D omet les parenthèses de l’écran de Slater et écrit 11,15. Le calcul décrit est 34 − (2 × 1 + 8 × 0,85 + 7 × 0,35) = 34 − 11,25 = 22,75. Le résultat de l’item est cohérent, mais les étapes imprimées comportent une coquille. La clé officielle est conservée ; vérifier ce point dans la ronéo et, si nécessaire, le faire préciser par l’enseignant.

===== 2020s2 thermo Q28 ID1 CLE BD =====
SUJET ORIGINAL
p338
Dans un réacteur dont l’enceinte est indilatable, on effectue la réaction suivante :
2 A(s) + 3 B(g) ↔C(l) + 4 D(g)                  ∆Hr = -100 kJ.mol-1
A. La valeur de ∆Hr permet de savoir que la réaction est thermodynamiquement favorisée
B. Si on diminue la température, la réaction est déplacée vers la droite
C. Si on ajoute du N2(g), la réaction est déplacée vers la droite (N2(g) n’étant pas : A, B, C, D)
D. Si on ajoute du C(l), la réaction est déplacée vers la gauche
E. Si on ajoute du A(s) la réaction est déplacée vers la droite
DETAIL ORIGINAL
BD
A. FAUX : Le ΔHr permet de savoir si la réaction est endothermique ou exothermique donc savoir si elle
dégage ou consomme de la chaleur. Le caractère thermodynamiquement favorisé = savoir si la réaction
est spontanée ou non correspond au ΔG
B. VRAI : Le système s’oppose à notre action, il va donc chercher à augmenter sa chaleur donc déplacer
l’équilibre dans le sens exothermique ce qui, dans ce cas, déplace l’équilibre vers la droite.
C. FAUX : le système veut se déplacer dans le sens d’une diminution du nombre de mole de gaz or il y a
plus de mole de gaz à droite que à gauche donc déplacement de l’équilibre vers la gauche
D. VRAI : Déplace l’équilibre dans le sens de son élimination soit vers la gauche
E. FAUX : L’ajout de solide ne déplace pas la réaction
DETAIL SITE (si différent)
NOTES
Le corrigé suppose qu’ajouter l’espèce notée (l) déplace nécessairement l’équilibre. Cette conclusion dépend de son statut : l’activité d’un liquide pur formant une phase distincte reste approximativement égale à 1 ; en ajouter ne déplace alors pas l’équilibre tant que la phase subsiste. Pour un constituant dissous dans un mélange liquide, son activité peut au contraire changer. L’énoncé ne précise pas ce point. La ronéo introduit le quotient réactionnel et les activités, mais ne résout pas cette ambiguïté de phase ; faire confirmer l’hypothèse du QCM dans le cours d’équilibres hétérogènes.
L’enceinte est indilatable. Dans le modèle des gaz parfaits à température constante, ajouter N₂ inerte augmente la pression totale mais laisse chaque pression partielle réactive pᵢ=nᵢRT/V inchangée ; cela ne déplace donc pas l’équilibre. Le verdict faux de l’item « vers la droite » peut être conservé, mais la justification « vers la gauche » est litigieuse. La table de la ronéo fournie contient elle aussi cette difficulté : il faut faire préciser l’hypothèse du cours. La clé officielle est conservée ; vérifier ce point dans la ronéo et, si nécessaire, le faire préciser par l’enseignant.
