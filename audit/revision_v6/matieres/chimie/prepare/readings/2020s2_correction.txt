Concernant l’atome 34Se :
Aide aux calculs :
0,35×2 = 0,7 ; 0,35×3 = 1,05 ; 0,35×4 = 1,4 ; 0,35×5 = 1,75 ; 0,35×6 = 2,1 ; 0,35×7 = 2,45 ;                    0,35×8 = 2,8
; 0,85×2 = 1,7 ; 0,85×3 = 2,55 ; 0,85×4 = 3,4 ; 0,85×5 = 4,25 ; 0,85×6 = 5,1 ;                 0,85×7 = 5,95 ; 0,85×8 = 6,8
A. Il possède 16 électrons de valence
B. Il possède 28 électrons de cœur
C. L’ion Se2+ présente une configuration de gaz rare
D. Sa charge nucléaire effective, pour un électron 3p, est égale à 22,75
E. Dans la classification périodique, il est situé dans la même colonne que 8O
BDE
A. FAUX : 34 Se : 1s2 2s2 2p6 3s2 3p6 4s2 3d10 4p4 ; atome du bloc p donc pour déterminer le nombre
d’électrons de valences on prend les ns + np de la dernière couche. Sois 2 + 4 = 6 électrons de valences
B. VRAI : Les électrons de cœurs étant tous les électrons qui ne sont pas de valences on a :       34 – 6 = 28
C. FAUX : Un gaz rare a une configuration s2 p6 ; l’ion Se2+ est l’atome de Se à qui on a arraché 2 électrons
; ça configuration étant 4s2 4p4 à l’état normal, si on lui arrache 2 électrons ça configuration sera 4s2
4p2
D. VRAI : On étudie un électron sur la couche 3p donc on prend en compte les électrons présents sur la
couche 1s, 2s 2p et 3s 3p en oubliant pas les coefficients d’écrantage ; au final on a : 2 électrons sur la
couche 1s, 8 électrons sur la couche 2s 2p et 7 électrons sur la couche 3s 3p car l’électrons que l’on
étudie ne s’écrante pas lui-même ; 34 - 2*1 + 8*0,85 + 7*0,35 = 34 - 2 + 6,8 + 2,45 = 34 - 11,15 = 22,75
E. VRAI : 8O : 1s2 2s2 2p4 ; 34 Se : 1s2 2s2 2p6 3s2 3p6 4s2 3d10 4p4 ; Ils possèdent le même nombre d’électrons
sur leur dernière couche p, ils sont donc sur la même colonne.

D. VRAI : Déplace l’équilibre dans le sens de son élimination soit vers la gauche
E. FAUX : L’ajout de solide ne déplace pas la réaction
